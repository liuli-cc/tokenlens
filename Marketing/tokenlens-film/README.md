# TokenLens — AI 工作，自有节奏

全新原创宣传片，32 秒，1920 × 1080，60 fps，120 BPM。

## 创作提示词

为 TokenLens 制作轻快、有节奏、流畅的产品宣传片。以一座持续存在的黑色灵动岛为视觉主角，从一个节拍点自然展开，五款助手的原始图标向它汇合，用量数字随节奏增长，岛体在任务完成时轻轻压缩回弹，紫色描边和柔光共同回应。随后同一个主体进入 Mac 与 Windows 的画面，最后收束成 TokenLens 标识。全片保持同一空间中的物体连续运动，不使用幻灯片、翻页、整页擦除或硬切。米白、墨黑、苔绿构成主色，提醒段由岛体扩散出的深色圆形进入夜色。字体简洁、宽阔，大字短句；每个重点留足阅读时间。原创鼓、弹性 bass、温暖 pluck 与和弦建立轻盈 groove，声音变化与视觉变化共同落在节拍上。不添加口播，不沿用之前视频的任何要求。

## 时间结构

| 时间 | 连续动作 | 内容 |
| --- | --- | --- |
| 0–4 秒 | 点 → 灵动岛 | AI 工作，自有节奏 |
| 4–10 秒 | 五个标识向同一主体汇合 | 五位助手，一个焦点 |
| 10–16 秒 | 同一岛体展开，数字与细线增长 | 用量、上下文，一眼看清 |
| 16–22 秒 | 深色圆形扩散、小幅回弹与软件色柔光 | GPT / Codex 完成提醒 |
| 22–26 秒 | 同一主体进入双平台设备 | macOS 与 Windows |
| 26–32 秒 | 岛体收束成品牌标识 | TokenLens 与下载地址 |

## 预览与修改

```sh
npm ci
npm run dev
```

打开终端打印的本机地址，选择 `TokenLens-Work-In-Flow`。文字、主岛形变、背景轨迹等图层在 Remotion Studio 中可选中编辑。配乐源文件位于 `tools/create_soundtrack.py`。

如需导出，使用：

```sh
npx remotion render src/index.ts TokenLens-Work-In-Flow out/TokenLens-Work-In-Flow.mp4 --codec=h264 --crf=17
```

已设置 ANGLE 图形后端，避免本机默认图形后端在双平台镜头产生平铺错误。本机优先使用已安装的 Google Chrome，其他机器使用 Remotion 的浏览器默认选项。

## 素材与产品真实性

- 音乐为原创合成，32 秒、48 kHz 双声道，无外部采样。峰值 −1.0 dBFS，综合响度 −14.80 LUFS；生成器与来源声明随项目保留。
- 第三方标识来自已安装应用的原始图标。`public/brand/sources.json` 记录来源，第三方商标归其权利人所有。
- 字体是 Noto Sans SC，OFL 许可随文件附带，预览不依赖在线字体。
- 界面及数字是宣传演示，片中保留演示说明；实际数值依本机可读取记录而定。
- 完成提醒展示 GPT / Codex；可读取的完成来源目前还包括 DeepSeek Harness。未把其他三款助手展示成支持自动完成提醒。
- 视频源码独立于应用源码，没有修改 TokenLens 主体功能，也没有发布到外部平台。
